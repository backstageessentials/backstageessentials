Accessibility

How this site is built, what was tested, and what was not.

← index—

This statement covers backstageessentials.com, all five sheets, the error page, and this page.

Standard

The site aims to meet Web Content Accessibility Guidelines (WCAG) 2.1 Level AA.

Conformance

Based on the evaluation below, the site conforms to WCAG 2.1 Level AA. That claim covers what was tested. It does not cover testing with assistive technology by the people who rely on it, which has not been done.

How it was evaluated

The site was tested in November 2026 using axe-core 4.10.2, against the WCAG 2.0 Level A and AA and the WCAG 2.1 Level A and AA rule sets. All seven pages returned zero violations.

Color contrast was measured separately. These pages use a drafting grid built from repeating gradients, and automated tools cannot resolve a background color behind text when the background is a gradient. Every text element was therefore measured directly against the background it renders on. All text meets or exceeds 4.5:1.

Text resizing was tested at 200 percent. No page produced horizontal scrolling or lost content.

What the site does

  • Semantic landmarks on every page: header, main, navigation, and footer
  • A skip link as the first focusable element
  • A visible focus indicator on every link
  • Text contrast at or above 4.5:1
  • Alternative text on every image
  • Heading levels in order, none skipped
  • Table headers marked with scope
  • Text that resizes to 200 percent without horizontal scrolling
  • A reduced motion rule for visitors who set that preference
  • No forms, no cookies, no analytics scripts, and no third party fonts

Known limitations

The site has not been tested with screen readers by people who use assistive technology daily. Automated testing finds structural problems. It does not establish that a page is usable.

My curriculum vitae is also offered as a PDF download. I have not assessed that file for accessibility. The complete CV is published as a web page on this site, and that version is what this statement covers.

Telling me about a problem

If something here does not work for you, write to me at bill@backstageessentials.com. I read my own mail and I will reply within five business days.
